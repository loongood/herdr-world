# Herdr World 多语言(i18n)支持设计 — 阶段 1:Web 框架与核心界面

日期:2026-11-14
状态:已与需求方确认的分节设计

## 1. 背景与目标

Herdr World 当前所有面向用户的文本均为硬编码英文,无任何 i18n 基础设施:

- Web 端:约 315 个 `.tsx` 组件,UI 文本以 JSX 内联英文字符串散布(~352 个文件于 `web/src/components/`);
- 服务端:`server/src/cli/` 输出、`server/src/verbs/` 等错误消息;
- 静态站点:`site/` 手写英文 HTML;
- 无日期/格式化库,`shared/assistant.ts` 与 `server/src/assistant/*.ts` 存在硬编码 `"en"` / `"en-US"` 的 `Intl` 调用。

目标:支持简体中文(zh-Hans)与繁体中文(zh-Hant),采用**分阶段交付**。

## 2. 已确认的需求决策

| 决策点 | 结论 |
| --- | --- |
| 覆盖范围 | Web 界面、服务端用户可见消息、文档站点、CLI 输出——全部 |
| 交付方式 | 分阶段(每阶段独立验收) |
| 语言决定机制 | 自动检测浏览器语言 + 设置中手动覆盖并持久化 |
| 简繁关系 | 独立维护两份翻译(术语各自地道,非自动转换) |
| 首期 Web 范围 | i18n 框架 + 核心界面(设置对话框、主导航、全局状态提示) |
| 日期时间 | 随所选语言本地化(原生 Intl,不加依赖) |

## 3. 总体路线图

| 阶段 | 内容 | 交付物 |
| --- | --- | --- |
| **1(本设计)** | Web i18n 框架 + 语言偏好 + 核心界面翻译 + 日期时间本地化 | 三语言可切换的可用框架 |
| 2 | 其余 Web 界面逐模块迁移(Town/Board/Desk/Spaces/聊天/终端等) | 全界面覆盖 |

未迁移的界面继续显示英文,是设计内的正常状态。

## 4. 技术选型:自研轻量 i18n 模块(已定)

不引入任何运行时依赖。与仓库现状一致(无外部状态/格式化库,自研 store,严格 size ratchet)。理由:插值场景少、中文无复数需求、原生 `Intl` 足够;类型化字典提供编译期完整性检查。

否决的备选:react-i18next(依赖与体积超出需要)、react-intl / FormatJS(ICU 语法学习成本高,能力冗余)。

## 5. i18n 模块架构

新建 `web/src/i18n/`:

```
web/src/i18n/
├── index.ts        # 导出 useT()、t()、语言状态、格式化助手
├── locales.ts      # Locale = "en" | "zh-Hans" | "zh-Hant" 与语言清单
├── en.ts           # 英文基准字典(唯一事实来源)
├── zh-Hans.ts      # 简体字典(类型: Dictionary)
├── zh-Hant.ts      # 繁体字典(类型: Dictionary)
└── format.ts       # Intl.DateTimeFormat / RelativeTimeFormat 封装
```

### 字典格式

按界面域分组的嵌套对象,键为稳定语义名。`en.ts` 导出 `type Dictionary = typeof en`;`zh-Hans.ts`、`zh-Hant.ts` 必须满足同一类型——**编译期强制三份词典键结构一致**。

```ts
// en.ts
export const en = {
  settings: { title: "Settings", language: "Language" },
  status: { syncFailed: "Failed to update automatic sync settings" },
} as const;
export type Dictionary = typeof en;

// zh-Hans.ts
import type { Dictionary } from "./en";
export const zhHans: Dictionary = {
  settings: { title: "设置", language: "语言" },
  status: { syncFailed: "更新自动同步设置失败" },
};
```

### 翻译函数

点路径取词 + `{name}` 插值,纯函数:

```ts
t("settings.language")                     // → "语言"
t("status.agentStarted", { name: "Rex" })  // 插值
```

### 加载策略

`en` 静态导入作兜底;`zh-Hans` / `zh-Hant` 经 `import()` 动态加载,选中时才下载,符合 PWA 体积要求。

## 6. 语言偏好与切换 UI

**决策顺序**(启动时):

1. localStorage 偏好(用户显式选择)→ 用它;值为 `"auto"` 时走检测;
2. 检测 `navigator.language`:`zh-TW` / `zh-HK` / `zh-Hant` → 繁体;其余 `zh-*` → 简体;其他 → 英文;
3. 异常兜底 → 英文。

**存储**:复用 `web/src/appearance.ts` 既有偏好模式——`worldLocalStorage`(前缀 `herdr-world:foundation-v2:`)新增 `language` 键,配套 `normalizeLanguage()` / `serializeLanguage()` 纯函数,与 `loadZenMode()` 等同构。只存显式选择;默认状态存 `"auto"` 以支持"改回跟随浏览器"。

**跨标签页同步**:复用 `browserStorage.ts` 的 storage 事件监听,切换即时生效于所有打开的标签页。

**设置入口**:`ConfigurationDialog.tsx` 外观区新增 "Language / 语言" 下拉(选项以各自语言原文显示:English / 简体中文 / 繁體中文),改选即生效并持久化。纯客户端,无路由变化。

**HTML lang**:切换时更新 `document.documentElement.lang`(`en` / `zh-CN` / `zh-TW`)。

## 7. 日期时间格式化

`format.ts` 提供 `formatDate()` / `formatTime()` / `formatDateTime()`,内部 `Intl.DateTimeFormat`,locale 跟随当前语言。相对时间用 `Intl.RelativeTimeFormat`。

| 语言 | formatDateTime 示例 |
| --- | --- |
| en | `Nov 14, 2026, 9:30 AM` |
| zh-Hans | `2026/11/14 09:30` |
| zh-Hant | `2026/11/14 上午9:30` |

阶段 1 仅接入 `web/src` 内浏览器端格式化调用点;`shared/` 与 `server/` 的硬编码 locale 属阶段 3。

## 8. 错误处理与兜底

1. **键缺失**:编译期由 `Dictionary` 类型拦截;运行时 `t()` 取不到键返回英文原文或键名,绝不显示空白;
2. **词典动态加载失败**:回退英文并 `console.warn`,界面不阻塞;
3. **非法语言值**:`normalizeLanguage()` 校验,非法即走检测流程;
4. **插值参数缺失**:原样保留 `{placeholder}`。

## 11. 测试策略

遵循仓库现有 bun test + happy-dom 模式:

1. **单元测试** `web/src/i18n/`:语言检测(`zh-TW`→繁、`zh-CN`→简、未知→英)、`t()` 取词与插值、`normalizeLanguage()` 非法值兜底、动态加载失败回退;
2. **组件测试**:`ConfigurationDialog` 语言选择器——改选即切换、localStorage 持久化、跨标签同步事件;
3. **编译期保障**:简繁字典 `Dictionary` 类型约束(typecheck 兜底)。
