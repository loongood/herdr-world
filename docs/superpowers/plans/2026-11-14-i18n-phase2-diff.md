# i18n Phase 2 — Module 24: Diff viewers

Plan for translating the diff review surfaces: `DiffContentView.tsx` and
`DiffViewerPanel.tsx`.

## Goal

Every user-facing string in the two diff viewers comes from the `t()`
dictionary; a new `diff` domain holds the 61 new keys, and the three
dictionaries stay in sync.

- [x] Add the `diff` domain (61 keys) to `en.ts`, `zh-Hans.ts` and
      `zh-Hant.ts`, keeping placeholder parity.
