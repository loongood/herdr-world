Part of the i18n design (`docs/superpowers/specs/2026-11-14-i18n-design.md`),
phase 2 module 9. Executes inline per the established per-module workflow
(follows module 8, committed as `32e9d609`).

## Scope

Migrate the Desk surfaces to the dictionary:

- `web/src/world/DeskView.tsx` — modes, attention summary counts, folding
  search, lanes (Needs you / To review / In flight), cards (ages, ask
  prefixes, receipt facts, actions), directory groups, reviewed view,
  review toast and the key legend.

  outside-filter panel and its reveal buttons.

  messages thrown as reveal errors.

  popover's default name.
- `web/src/world/town/TownDeskTitle.tsx` — the nameplate's group aria.

Not migrated:

- `web/src/world/DeskView.browser.tsx` — a browser-driver test fixture
  asserting the English UI; stays untouched and keeps passing under the
  default English locale.
- `web/src/world/deskAgentLabels.ts` — assembles data (names, paths); no
  English copy.

## Dictionary

New `desk` domain (89 keys) in `en.ts`, mirrored in `zh-Hans.ts` /
`zh-Hant.ts`. Notable shapes:

- `DESK_MODES` became a plain mode array plus `modeLabel()` reading
  `MODE_LABEL_KEYS` at render time (the constant-table trap: module-level
  English labels would freeze before lazy dictionaries load).
- Singular/plural split where English inflects: needsYouOne/Many,
  toolCallsOne/Many, filesEditedOne/Many, quietAgentsOne/Many,
  agentsInGroupOne/Many.
- `filesEdited*` takes the count as a pre-composed string so the
  truncation `+` ("3+") stays inside the number in every language.
- The review toast keeps its `<strong>` around the name via
  `markedLead` / `markedTail`.
- The reveal messages keep the words the deskReveal test asserts
  ("Cached", "unavailable", "session").
- `BadgePopover`'s `label` prop became optional-with-dictionary-default
  (`label ?? t("desk.pullRequest")`), since a default parameter cannot
  call the component's `useT`.
